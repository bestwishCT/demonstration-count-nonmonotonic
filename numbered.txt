17: G More Experiments
18: G.1 Retrieval Analysis
19: Oracle. Since the original datasets do not contain
20: gold passages at the same granularity level as our
21: setting (100-word passages), we approximate gold
22: passages by running the following algorithm on the
23: top-100 retrieved passages. We first calculate the
24: recall score for each passage. Then, we sort the
25: passages using their recall score and take the top 5
26: passages as our initial oracle set. Finally, we iterate
27: through all passages that were not initially in the or-
28: acle set and try to replace the passages in the oracle
29: set in a greedy fashion: we calculate the change in
30: the recall score of the oracle set for every possible
31: replacement and proceed with the replacement that
32: results in the largest recall improvement. The set
33: of 5 oracle passages were able to match the recall
34: scores of the top-100 retrieved passages.
35: Detailed retrieval results. We show detailed re-
36: trieval results in Tables 12, 13, and 14.

61: G.4 Fine-tuned Models
62: To better understand the differences between fine-
63: tuned models and prompted large language mod-
64: els, we train state-of-the-art question answer-
65: ing model, Fusion-in-Decoder (FiD; Izacard and
66: Grave (2021)), and evaluate it in conjunction with
67: POST CITE. Due to the lack of training data with
68: citation annotation, we first train a T5-base FiD
69: model for 5 epochs on the ASQA training set with
70: a batch size of 64 and a learning rate of 1e-4. Dur-
71: ing evaluation, we use POST CITE to add citations
72: to the output. We also usek = 5 passages during
73: both training and evaluation of the FiD model.
74: Then, we evaluate this model on both ASQA
75: (in-domain) and ELI5 (out-of-domain), and the re-
76: sults can be found in Tables 17 and 18. Note that
77: this is not a direct comparison, as ALCE assumes
78: only evaluation data available and uses only few-
79: shot data for prompting. As the results show, the
80: FiD baseline still significantly lags behind prompt-
81: ing ChatGPT in both correctness and citation qual-
82: ity (even though it is trained on 4000+ examples).
83: When tested on another dataset (ELI5), FiD per-
84: forms even worse, showing that it is challenging
85: to solve the problem by fine-tuning a small pre-
86: trained model.
